# Doggo
Sistema IoT embarcado em ESP32 atuando como Servidor HTTP/TCP para automação de pet shop/canil. Permite o acompanhamento da temperatura da água, controle de dosagem de ração via balança digital e acionamento remoto de atuadores (servomotor e relé). Conta com log persistente em memória Flash (LittleFS) e reconexão automática Wi-Fi.
